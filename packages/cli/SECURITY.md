# Security policy

## Supported versions

Only the latest published version of `@vitalscope/sdk`, `@vitalscope/protocol` and `@vitalscope/cli` receives security fixes.

## Reporting a vulnerability

Please do not report vulnerabilities in public. Report them privately through [GitHub's security advisories](https://github.com/emircanbakar/vitalscope/security/advisories/new), or email **ecbakar.dev@gmail.com**. Include:

- the affected package and version
- what an attacker can do, and how to reproduce it

You will get a first response within 72 hours.

When a vulnerability is confirmed, a fixed version is published and the affected versions are deprecated on npm with a message pointing to the fix.
